➕ Benutzerkonto anlegen

Hier kann ein vorläufiges Konto mit Startpasswort angelegt und direkt einem Spieler zugeordnet werden. Das Startpasswort wird dem Benutzer mitgeteilt und sollte anschließend geändert werden.

–

Benutzerverwaltung

Ein Benutzerkonto kann hier weiterhin Rollen und Mannschaften erhalten. Ein Spieler kann über „Spielerkonten“ mehrere Benutzerkonten besitzen.

–

👤 Spielerkonten

Variante B: Ein Spieler kann mehrere Benutzerkonten/E-Mail-Adressen haben. Ein Konto kann später ergänzt, als Hauptkonto markiert oder entfernt werden. Das eigentliche Passwort bleibt beim jeweiligen Supabase-Benutzerkonto.

💡 Bei der eigenen E-Mail kann der Benutzer jederzeit über „Passwort per E-Mail zurücksetzen“ einen sicheren Link anfordern. Der Admin kann denselben Reset-Link ebenfalls auslösen.

Mannschaften

Die Mannschaftsnamen werden aus den vorhandenen Team-Zuordnungen und Spieler-Stammdaten zusammengestellt.
